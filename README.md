# 算数プリント作成

小学1年〜中学3年の計算・図形・関数（グラフ）問題のプリント（問題用紙・解答用紙）を PDF で作るサイトです。
サーバーを使わず、ブラウザの中で Python（Pyodide）を動かして PDF を作ります。GitHub Pages で無料公開できます。

## できること

- 出題範囲（約100単元）と問題数を選び、複数日分を1つの PDF にまとめる
- 日にちごとに単元・問題数を選び直す
- 自作問題を登録して出題する（`{3/4}` で分数、`x^2` で指数、`√{12}` で平方根）
- 家庭教師・塾向け：生徒ごとの設定保存、生徒名・教室名・ひとこと、かかった時間・先生のコメント・保護者の確認欄
- 書体は「教科書風」（明朝＋TeX の数式フォント）か「ゴシック」

## ファイル

- `index.html` 画面
- `py/bundle.b64.txt` 問題を作るプログラム（worksheets）と reportlab を zip にして base64 にしたもの
- `fonts/` IPAex明朝・IPAゴシック（IPAフォントライセンス）、KaTeX フォント（MIT ライセンス）
- `pyodide/` ブラウザで Python を動かすための Pyodide 0.26.4
- `pdf.min.js` / `pdf.worker.min.js` プレビュー表示用の PDF.js 3.11.174
